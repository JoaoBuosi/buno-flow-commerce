# Avaliação com dados reais — 09/11/2026

Fonte: Chen, D. (2015), UCI Online Retail, CC BY 4.0, https://doi.org/10.24432/C5BW33

A base com 541.909 transações históricas de 2010–2011 foi baixada na CI a partir da fonte UCI, processada sem exportar identificadores de clientes, e usada para previsão semanal de unidades por SKU.

Experimento 1: modelo Ridge com transformação log, 200 SKUs, validação temporal, 8.400 observações de treino, 1.600 de teste (últimas 8 semanas). MAE da previsão sem limite foi superior a 4 milhões de unidades; baseline média móvel MAE 157,7937. **Reprovado**.

Experimento 2: mesmas divisões e método, com limite de extrapolação calculado apenas de features históricas. MAE do modelo 256,0931 unidades, baseline MAE 157,7937, WAPE 0,8933. Melhora sobre baseline = -62,3%. **Reprovado**; não se habilita o modelo.

- https://github.com/JoaoBuosi/buno-flow-commerce/actions/runs/42623121277

Conclusão: o pipeline de ML executa com dados reais e fornece evidências honestas, mas **não há modelo preditivo suficientemente validado para clientes**. Por enquanto, usar somente médias móveis descritivas com indicação de baixa confiança e dados insuficientes. Próxima etapa: coletar dados históricos de uma loja piloto sob autorização, redefinir target e testar modelos robustos, sem vazamento temporal ou de dados pessoais.
